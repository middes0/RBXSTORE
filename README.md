# RBXStore
Primeira versão da loja de Robux e Game Passes.

Arquivos: `index.html`, `style.css`, `script.js`.

Inclui home, catálogo, carrinho com localStorage, remoção, cupom `RBX10` (10%), checkout visual e layout responsivo.

Os produtos/preços são demonstrativos. Para operação real, substitua o catálogo e conecte meios de pagamento e entrega compatíveis com as regras das plataformas envolvidas.
